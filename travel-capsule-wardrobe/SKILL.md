# Travel Capsule Wardrobe Planner Skill
## 旅行胶囊穿搭规划 Skill

---
> v1.1 变更：补充标准 AI Skill frontmatter；第 13 节补充与 [[家庭游规划 skill]] 的双向联动说明（家庭游规划 skill 19.4 / 21 节已声明在行李清单阶段调用本 skill）。  
> v1.2 变更：强化「家庭分角色视觉输出」——按老人 / 成人 / 小孩生成每日 Look 与 AI 生图提示词；明确当日家庭色系协调；嵌入家庭游规划时默认开启家庭视觉包。

## 1. Skill 定位

### 名称
**Travel Capsule Wardrobe Planner**  
**旅行胶囊穿搭规划器**

### 核心定义
旅行胶囊穿搭，不只是“少带衣服”。

它的目标是：

> **用尽可能少、复用率尽可能高的衣物单品，构建覆盖整段旅程的多套完整 Look；同时综合目的地、天气、活动强度、拍照环境和个人风格，让每一套既适合当天真实出行，也与当天的旅行场景形成视觉呼应。**

核心公式：

> **少量单品 × 多种组合 × 多种风格 × 场景匹配 × 天气适配**

这个 Skill 解决的不是单一问题“今天穿什么”，而是：

> **这一趟旅行，最少应该带哪些衣服，才能在不同天气、不同目的地、不同活动和不同拍照场景下，组合出足够多、足够好看的风格？**

---

# 2. 核心原则

## 2.1 旅行优先，不从衣服开始
先理解：
- 去哪里
- 每天做什么
- 气温和天气
- 是否步行多
- 是否抱娃、带老人
- 是否坐飞机、高铁、邮轮
- 是否有正式晚餐
- 是否有重点拍照场景
- 是否可以中途回酒店换装

然后再决定应该穿什么。

---

## 2.2 胶囊不是“极简”，而是“高复用”
不追求每天都穿完全不同的衣服。

更重要的是：
- 每件核心单品尽量出现 2–3 次
- 但避免连续几天照片像同一套
- 通过上装、下装、鞋、帽子、马甲、丝巾、包等改变风格
- 同一件衣服在不同场景中可以呈现不同视觉身份

例如：
- 浅灰绿棉麻裤 + 绿条纹衬衫 = 松弛度假风
- 浅灰绿棉麻裤 + 克莱因蓝 Polo = 清爽海洋风
- 粉色衬衫 + 咖格裙 = 上海秋日文艺风
- 粉色衬衫 + 黑裤 = 轻松机场 / 日常风

---

## 2.3 追求“照片感受不同”，而不是“每天衣服不同”
这是本 Skill 非常重要的判断标准。

即使复用了同一件衣服，只要通过以下方式改变视觉：
- 换下装
- 换鞋
- 加 / 去外套
- 换帽子
- 加马甲
- 换丝巾
- 换包
- 调整配色关系

最终照片就可以呈现完全不同的 Look。

---

## 2.4 已有衣物优先，非必要不买
如果用户已经拥有合适衣服：
- 优先重组真实衣柜
- 优先用替代关系解决问题
- 非必要不建议购物

只有存在明显结构性缺口时才建议添置，例如：
- 没有防雨防风层
- 没有适合长时间步行的鞋
- 没有适合正式晚餐的单品
- 缺少真正百搭的下装
- 温差明显但没有轻薄外层

---

## 2.5 功能层与造型层分开
不同单品承担不同任务。

例如：
- 冲锋衣 = 防风 / 防雨
- oversize 衬衫 = 轻松休闲
- 西装马甲 = 城市造型
- 丝巾 = 低体积视觉变化
- 假袖披肩 = 低成本增加层次
- 草帽 = 度假氛围
- 棒球帽 = 运动 / 机场 / 亲子

避免带多件“功能完全相同”的单品。

---

# 3. 使用场景

适用于：

- 城市旅行
- 邮轮旅行
- 海岛旅行
- 自驾旅行
- 亲子旅行
- 家庭旅行
- 带老人旅行
- 多气候、多温差旅行
- 有街拍 / 纪念日晚餐 / 家庭照需求的旅行
- 用户想少带行李但每天仍有不同视觉风格
- 用户希望尽量使用现有衣柜

需要结合：

- 提前 7 天以上：看趋势
- 出发前 2–3 天：重新核验
- 出发前 1 天：做最终调整

# 5. 两阶段工作流

## Phase A：用户还没有提供衣柜

不要强迫用户先整理衣服。

先直接根据：
- 行程
- 天气
- 景点
- 活动强度
- 拍照场景
- 用户偏好

生成一套“理想旅行胶囊衣橱”。

### 输出包括：

#### 1. 旅行主色盘
建议结构：
- 2–3 个基础色
- 2–3 个变化色
- 1 个点缀色

例如：
- 白 / 卡其 / 黑 = 骨架
- 粉 / 蓝 / 绿 = 变化
- 黄 = 点缀

#### 2. 推荐核心单品
建议包含：
- 4–6 件上装
- 3–5 件下装
- 1–2 条连衣裙
- 2–3 件不同功能的外层
- 2 双鞋
- 1–2 顶帽子
- 1 个主力功能包
- 1–3 个低体积配饰

#### 3. 每日完整 Look
每天包含：
- 帽子
- 上衣
- 下装 / 连衣裙
- 外层
- 鞋
- 包
- 配饰

同时说明：
- 为什么适合当天景点
- 为什么适合天气
- 为什么适合活动强度
- 为什么适合拍照
- 配色是否协调
- 是否存在潜在问题

#### 4. 用户下一步
邀请用户从自己的衣柜里寻找“相似功能和相似颜色”的单品，而不是要求完全一致。

---

## Phase B：用户提供衣服 / 图片后

进入“真实衣柜重组模式”。

### Step 1：建立衣柜池
分类：
- 上装
- 下装
- 连衣裙
- 外套
- 马甲
- 鞋
- 帽子
- 包
- 配饰

### Step 2：判断单品角色
例如：
- 机场主力
- 邮轮主力
- 海边主力
- 城市街拍
- 正式晚餐
- 家庭装
- 防雨备用
- 拍照亮点

### Step 3：用真实衣柜替换理想方案
不是推翻原方案，而是保留：
- 场景功能
- 配色逻辑
- 舒适逻辑
- 风格目标

例如：
原方案需要白裤，但用户没有白裤：
- 用卡其裤
- 浅灰绿裤
- 米色裤
替代。

### Step 4：检查重复率
检查：
- 某条裤子是否出现过多
- 某种颜色是否连续几天重复
- 外套是否全部同类
- 照片是否缺乏变化

优化顺序：
1. 先换下装
2. 再换外层
3. 再用鞋帽包配饰变化

### Step 5：主动删减
给单品分类：
- 必带
- 可选
- 候补
- 不建议带

明确告诉用户哪些可以留在家里。

# 6. 场景适配规则

## 机场 / 高铁 / 抱娃
优先：
- 裤装
- 舒适运动鞋
- 易活动
- 不易皱
- 外层易穿脱

---

## 邮轮登船
优先：
- 清爽
- 海洋感
- 有度假感
- 方便走动

---

## 邮轮巡航
可以增加：
- 半裙
- 草帽
- 墨镜
- 丝巾
- 轻松度假色

注意甲板风。

---

## 正式晚餐
优先：
- 连衣裙
- 半裙 + 精致上衣
- 乐福鞋 / 舒适精致鞋

带宝宝时：
正式度不能牺牲行动便利。

---

## 海岛 / 济州 / 自然景区
优先：
- 裤装
- 运动鞋
- 防风层
- 防雨层
- 自然色
- 绿色 / 卡其 / 白 / 蓝

有雨时：
- 浅色棉麻慎用
- 纱裙慎用
- 大草帽慎用

---

## 城市街拍
适合：
- 半裙
- 小立领衬衫
- 马甲
- 乐福鞋
- 丝巾
- 卡其 / 咖 / 粉 / 黑白

---

## 家庭装 / 亲子装
不要求完全同款（同款往往不舒适、也不好买）。

优先：
- 同色
- 同色系
- 同一个点缀色
- 相似明度

### 当日家庭色系协调（强制规则）
当输出包含 2 位及以上家庭成员时，**每一天先定一个「家庭日色盘」**，再为各角色拆 Look：

1. **主色 1 个**：当天全家照片里最先被看见的颜色（可落在成人或小孩身上）。
2. **调和色 1–2 个**：老人、成人、小孩各自取主色的邻近色或同色系降饱和版本。
3. **点缀色最多 1 个**：丝巾、帽子、童装小配饰、鞋带等；避免每人各带一个高饱和色。
4. **角色差异靠版型与场景，不靠颜色打架**：老人偏舒适宽松；成人偏可走可拍；小孩偏活动安全与易穿脱。
5. **合影优先日**（邮轮甲板、纪念日晚餐、标志性景点）：同色系要求提高一档；日常步行日可放宽为「同明度中性底 + 一个点缀色」。

# 7. 配色规则

## 基础色
- 白
- 米
- 卡其
- 灰
- 黑
- 海军蓝

## 变化色
- 粉
- 草绿
- 浅蓝
- 紫
- 橙

## 点缀色
- 黄
- 红
- 宝蓝
- 亮粉

## 搭配原则
- 高饱和上衣 + 中性下装
- 彩色鞋 + 基础色服装
- 彩色外套时，其他颜色尽量收敛
- 配件提亮，不抢戏
- 同一天尽量控制 1 个视觉主角

# 10. Visual User Mode
## 视觉用户模式

当用户说：
- “我是视觉动物”
- “没有图没有感觉”
- “做长图”
- “画出搭配”
- “做穿搭看板”

则优先生成视觉版。

## 推荐形式
竖版旅行 Lookbook / 穿搭长图。

### 长图结构

#### 顶部
- 旅行名称
- 日期
- 色盘
- 穿搭策略

#### 第一部分：携带单品
按类别展示：
- 上装
- 下装
- 裙装
- 外套
- 马甲
- 鞋
- 帽子
- 包
- 配饰

#### 第二部分：每日 Look
每天一个完整造型。

每套显示：
- Day
- 目的地
- 衣服组合
- 风格关键词
- 配色关系

### 视觉要求
- 不必使用真人
- 可用卡通 / 时尚插画
- 重点表现颜色、轮廓和层次
- 尽量忠于用户真实衣服
- 不凭空增加用户没有的关键单品
- 场景背景应与目的地呼应
- 让用户一眼就能判断“这套我喜不喜欢”

# 10A. 家庭分角色视觉包（v1.2）
## Family Role Lookbook + AI Image Prompts

本节补齐：不只做「一个人的长图」，而是**按家庭角色出图**，并给出可直接喂给生图模型的提示词。

### 何时启用（默认开启）
满足任一即启用，无需用户再说「我要图」：

1. 由 [[家庭游规划 skill]] 在行李 / Look 阶段调用本 skill；
2. 行程中出现老人、低龄宝宝、亲子合影节点；
3. 用户说：画穿搭、做 Lookbook、一家怎么穿、同色系家庭装、生成衣服图。

仅服务「单人旅行穿搭」且用户明确不要图时，可只输出文字表。

### 服务对象（可通用，也可特化）
| 模式 | 说明 |
|------|------|
| **通用模式** | 任意旅行者：输出个人胶囊 + 每日 Look +（可选）单人生图提示词 |
| **家庭模式** | 老人 / 成人 / 小孩分角色胶囊与每日 Look；每天一组家庭色盘；合影日额外输出「全家同框」提示词 |
| **特化人群** | 可只服务其中一类（如「只给婆婆」「只给宝宝」），其余角色用色盘对齐但不强制出完整衣橱 |

### 每日必须产出的结构化块
对行程中的每一天，输出：

```text
## Day N｜场景｜家庭日色盘
- 主色 / 调和色 / 点缀色（各写具体色名，勿只写「蓝色系」）
- 合影优先级：高 / 中 / 低

### 老人 Look
- 单品清单（含鞋、外套）
- 舒适与行动约束（是否久走、是否上下船、是否怕冷）
- 与家庭色盘的关系（主色落点 / 调和方式）

### 成人 Look（可拆妈妈 / 爸爸）
- 单品清单
- 抱娃 / 推车 / 拍照需求
- 与家庭色盘的关系

### 小孩 Look
- 单品清单（易穿脱、耐脏、防晒层）
- 午睡 / 户外活动约束
- 与家庭色盘的关系

### 全家同框说明（合影优先日必填）
- 站位建议（谁站中间、谁抱娃）
- 颜色节奏（谁持主色、谁持调和色）
```

### AI 生图提示词包（必须输出）
对每个角色、每一天，附一段**可直接复制到生图工具**的英文或中英双语 prompt（用户未指定语言时用中文主体 + 英文材质色词）。

**单人卡 Prompt 模板：**
```text
[角色：老人/成人女性/成人男性/幼儿]，全身站姿时尚插画，非写真脸，
穿着：[上装颜色材质版型] + [下装] + [鞋] + [外套/配饰]，
场景：[当日行程场景，如邮轮甲板/济州海岸/上海老城街]，
光线自然，突出衣物颜色与层次，干净背景或轻场景，
不要文字水印，不要额外虚构未列出的主单品。
```

**全家同框 Prompt 模板（合影日）：**
```text
同一画风家庭时尚插画，[人数]人同框：老人、成人、小孩，
统一色系：[主色] + [调和色] + 点缀[点缀色]，
各自穿着：[逐人一句单品]，
场景：[合影场景]，站位自然可抱娃，全身，强调「一家人像一套色盘但不撞款」，
不要Logo，不要夸张网红滤镜。
```

### 生图执行约定
1. **先出文字色盘与表格，再出图**；图必须服从当日家庭色盘。  
2. 图可用插画 / 扁平时尚稿 / 服装平铺拼贴；默认不追求真人脸一致性。  
3. 若用户上传了真实衣物照片：prompt 中写明「匹配参考衣物的颜色与版型」，禁止换成更时尚但用户没有的衣服。  
4. 老人 Look 禁止：高跟鞋、过紧连衣裙、难穿脱层次过多。  
5. 小孩 Look 禁止：纯白色易脏主力裤作为步行日唯一下装；优先耐脏中性色 + 一个点缀。  
6. 一次请求可并行生成：`老人单人` / `成人单人` / `小孩单人` / `全家同框`；优先保证合影日全家图。

### 嵌入家庭游规划时的交付物
当作为 `outfit_planner` 被调用时，除原有打包清单外，追加：

- 旅行家庭色盘（整趟）
- 逐日家庭日色盘
- 分角色每日 Look 表
- AI 生图提示词包（按日 × 角色）
- （若环境支持生图）直接生成插画/长图；不支持则至少交付可复制 prompt

# 11. 天气复核机制

## 距离出发 7 天以上
只做趋势版。

## 距离出发 2–3 天
重新确认：
- 温度
- 降雨
- 风力
- 体感温度

## 出发前 1 天
做最后一次调整：
- 哪天裙装改裤装
- 哪件外套随身
- 是否需要雨具
- 是否需要保暖层

# 12. Edge Cases

## 用户衣服很多
主动帮用户删减，而不是全部塞进行李。

## 用户衣服少
最大化复用。

## 某件衣服穿不下
立即从候选池移除。

## 用户明确不想购物
完全基于现有衣柜。

## 用户愿意买 1–2 件
只补结构性缺口。

## 用户提供实物图片
优先根据图片判断真实颜色、版型和材质。

### 与 [[家庭游规划 skill]] 的双向联动（v1.1）

- **下行调用**：家庭游规划 skill 在行李清单阶段（其 19.4 节"行李 Checklist"、21 节"按包逻辑"）会调用本 skill 的 `outfit_planner` 生成衣物包与每日 Look；本 skill 输出的打包清单直接并入家庭行李清单。
- **上行输入**：本 skill 优先接收家庭游规划 skill 已产出的行程输入（`trip_profile` / `daily_itinerary` / `weather_check`），不重复询问用户已提供过的行程信息。

- 每日景点

# 14. Quality Checklist

输出前检查：

- [ ] 是否真正结合了每天的行程？
- [ ] 是否考虑了目的地风格？
- [ ] 是否考虑温度、风雨和温差？
- [ ] 是否考虑步行、抱娃、老人？
- [ ] 是否避免同一条裤子过度重复？
- [ ] 是否形成多个明显不同的风格？
- [ ] 是否尽量复用已有衣物？
- [ ] 是否避免无必要购物？
- [ ] 是否让核心单品有合理复用？
- [ ] 是否保留真正宽松舒服的 Look？
- [ ] 是否有防风 / 防雨层？
- [ ] 是否有舒适步行鞋？
- [ ] 是否考虑照片中的色彩变化？
- [ ] 是否给出不带清单？
- [ ] 视觉用户是否得到长图？
- [ ] 家庭模式是否按老人/成人/小孩分角色输出？
- [ ] 每一天是否有明确的家庭日色盘（主色/调和/点缀）？
- [ ] 合影优先日是否有全家同框说明与生图提示词？
- [ ] 生图提示词是否未虚构用户没有的关键单品？

# 15. One-line Principle

> **先用旅行场景决定“这一趟需要哪些穿搭角色”，再用真实衣柜完成这些角色；用最少的衣服，组合出最多的风格，让每一套都既适合目的地、气温和活动，又在照片里有明显不同。**
