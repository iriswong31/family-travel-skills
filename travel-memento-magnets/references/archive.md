# 留档、同步与介绍文

## 本机目录
读取 Obsidian 已注册 vault，选择个人知识库而非无关工作项目；不确定目的地才询问。输出落在“旅行纪念/系列名/TRIP XXX/”，包含事实卡.md、原片及哈希、分层蒙版、drafts/approved/、print/、outline/、series.json（系列根目录）、制作记录.md。本地已有信息优先，拒绝覆盖用户文件。

每次输出留草稿；只有明确确认才更新认可状态与系列编号。记录下一块可用边、连接方向、物理尺寸和制造验证状态。若路径不可写先在任务工作区保存并请求权限，不能声称已写入。

## GitHub
本技能可发到用户指定或已有技能仓库，默认只发布通用SKILL、SOP、脚本及脱敏说明；不把真人原片/家庭母版/私人series.json纳入公开仓库。先检查远端内容、权限、脏改动；保留无关文件。同步验证远端提交，不把本地commit当已上传。仓库不明确时询问或选择已有同类skills仓库并说明。

## Get笔记
仅在用户请求时写介绍文并推送。文章应说明真实输入、流程、原片保真与可拼接前提、调用示例、安装位置及GitHub链接；不能吹成仅凭一张生图就保证制造级无缝拼接。可保存到“设计”知识库。使用幂等键避免重复创建，回读标题正文核验并存note_id。接口不可用时把推文.md及明确执行指令写回Obsidian，告知尚未推送；不伪造成功。
